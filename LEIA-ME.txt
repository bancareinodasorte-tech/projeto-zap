CANAL DE VENDAS RDS — V10 FINAL OPERACIONAL 10.2.2

PACOTE COM 11 ARQUIVOS.

INSTALAÇÃO / ATUALIZAÇÃO
1. No Supabase > SQL Editor, abra o arquivo MIGRACAO_V10_FINAL.sql deste pacote.
2. Execute TODO o arquivo uma única vez. Ele é incremental e NÃO apaga os dados V10 existentes.
3. No repositório GitHub usado pelo Render, substitua os arquivos do projeto pelos 11 arquivos deste pacote.
4. Confirme que o Render mantém as variáveis:
   SUPABASE_URL
   SUPABASE_SERVICE_ROLE_KEY
5. Faça o deploy e aguarde ficar Live.
6. Abra o site. O topo deve mostrar “V10 FINAL 10.2.2” e WhatsApp conectado.
7. Em Ajustes, confira: WhatsApp do escritório, preço, chave PIX e favorecido. Salve.
8. Use Diagnóstico V10. Todas as tabelas devem aparecer OK.

TESTE FINAL RECOMENDADO (1 CLIENTE)
A. Criar campanha com 1 contato válido e 2 etapas (ex.: etapa 2 após 5 min).
B. Ativar. A primeira mensagem deve sair somente no horário configurado.
C. A mensagem da campanha terá “COMPRE AGORA” com link vinculado ao código da campanha.
D. No cliente, clique no link ou envie “QUERO COMPRAR”.
E. Bot deve enviar 2 mensagens separadas:
   1) PREENCHER PEDIDO
   2) Quantidade / Nome / Contato
F. Responda preenchido, ex. Quantidade: 3. O sistema calcula R$ 9,00 se preço = R$ 3,00.
G. Envie uma imagem/PDF como comprovante. O pedido deve mudar para AGUARDANDO_CONFERENCIA.
H. No painel Compras, clique “Pagamento confirmado”.
I. Depois de enviar os bilhetes manualmente ao cliente, clique “Bilhetes enviados”. O bot envia a mensagem final e encerra o pedido.

CORREÇÃO CRÍTICA DE MENSAGENS / LID
- O sistema NÃO transforma mais IDs @lid em número de telefone.
- Ele prioriza senderPn / remoteJidAlt / participantAlt quando o WhatsApp fornece o número real.
- Se vier apenas LID, grava alerta e retorno, mas NÃO cria contato com número falso.
- As mensagens enviadas ficam em cache para atender pedidos de reenvio/recuperação de criptografia do WhatsApp Web.
- O pacote usa Baileys 6.7.24 (linha v6 corrigida) e bloqueia eventos de sincronização que não sejam novas notificações.

IMPORTANTE
- “Aguardando mensagem...” é uma mensagem do próprio WhatsApp quando um dispositivo vinculado ainda não conseguiu recuperar/descriptografar o conteúdo. Esta versão inclui as correções aplicáveis no sistema (destino PN/LID, cache getMessage, reenvio e uso conservador da sessão), mas a confirmação definitiva precisa ser feita no teste real entre os aparelhos conectados.
- Não use SQL antigo da V6/V10 anterior depois desta migração.
- Não apague a sessão zap_auth se o WhatsApp já estiver conectado.
