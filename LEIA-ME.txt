CANAL DE VENDAS RDS — V10 FINAL
================================

OBJETIVO
Versão reconstruída sobre um banco V10 próprio (tabelas rds10_*), sem depender das estruturas quebradas das versões V5/V6. A sessão do WhatsApp continua usando zap_auth para poder reaproveitar a conexão existente.

INSTALAÇÃO — ORDEM EXATA
1) SUPABASE
   - Abra SQL Editor > New query.
   - Cole TODO o conteúdo de MIGRACAO-V10.sql.
   - Clique Run UMA VEZ.
   - O resultado esperado no final é:
     CANAL DE VENDAS RDS V10 FINAL - BANCO INSTALADO COM SUCESSO
   - A migração é idempotente: pode ser executada novamente sem apagar dados V10.

2) GITHUB
   - No repositório atual, substitua os arquivos de mesmo nome pelos arquivos deste pacote.
   - NÃO renomeie app.js, server.js, index.html, styles.css, package.json, sw.js, manifest.webmanifest ou icone.svg.
   - MIGRACAO-V10.sql, LEIA-ME.txt e CHECKLIST-TESTE-V10.txt podem permanecer no repositório.

3) RENDER
   - Confirme as variáveis existentes:
     SUPABASE_URL
     SUPABASE_SERVICE_ROLE_KEY
   - O Start Command deve ser: npm start
   - Aguarde o deploy ficar Live.

4) PRIMEIRA ABERTURA
   - Abra Ajustes > Diagnóstico.
   - Todas as tabelas rds10_* devem aparecer OK.
   - Confira se WhatsApp está conectado. Se não estiver, gere novo QR.
   - Salve as configurações do bot e faça um teste para um número seu.

PRINCIPAIS RECURSOS V10
- Banco novo e independente das tabelas conflitantes V5/V6.
- Campanha em RASCUNHO não envia nada.
- Ativação cria a fila, mas só envia quando scheduled_at chegar.
- Sequência de lembretes por minutos, com imagem opcional em cada etapa.
- Segmentação por todos, grupo ou contatos individuais.
- CTA clicável PEDIR AGORA usando código curto da campanha.
- Interrompe futuros lembretes quando o cliente inicia pedido.
- Bot aceita QUERO COMPRAR e também frases como QUERO 2.
- Quantidade pode ser detectada diretamente da mensagem.
- Cliente novo que manda mensagem entra automaticamente na carteira.
- Opt-out: cliente pode pedir para parar mensagens e é excluído da automação.
- Handoff para escritório por palavras como ATENDENTE/ESCRITÓRIO.
- Comprovante por imagem/PDF gera alerta e muda o pedido de etapa.
- Confirmação de pagamento permanece manual pelo operador.
- Envio de bilhete pelo operador após pagamento confirmado conclui o pedido automaticamente quando for mídia/documento.
- Dashboard com fila, envios, entregas, leituras, interesses, comprovantes, compras e receita.
- Diagnóstico interno do schema V10.
- Importação VCF/CSV com prévia, nomes, duplicados e inválidos antes de salvar.

IMPORTANTE
A V10 foi validada por análise estática/sintática e consistência interna do pacote. A conexão real com Supabase, Render e WhatsApp depende das credenciais e do ambiente online; por isso use CHECKLIST-TESTE-V10.txt antes de operação em massa.
