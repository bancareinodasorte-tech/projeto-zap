CANAL DE VENDAS RDS — V6.0

OBJETIVO DESTA VERSÃO
- Nova base independente das tabelas antigas pz_* para parar de acumular remendos.
- Atendimento universal: qualquer número que mandar mensagem entra no fluxo.
- CTA de compra rastreável em cada etapa da campanha.
- Cliente que responde sai dos próximos lembretes daquela campanha.
- Pedido -> PIX -> comprovante -> conferência manual -> bilhetes enviados -> mensagem final.
- Importação VCF/CSV com prévia, duplicados e seleção antes de salvar.

INSTALAÇÃO
1. No Supabase > SQL Editor, execute o arquivo MIGRACAO.sql UMA VEZ.
2. No GitHub do projeto, substitua os arquivos antigos pelos arquivos deste pacote.
3. No Render mantenha/configure:
   SUPABASE_URL
   SUPABASE_SERVICE_ROLE_KEY
4. Faça o deploy.
5. Abra Ajustes e confirme PIX, favorecido e WhatsApp do escritório.
6. Se necessário, reconecte o WhatsApp por QR Code.

IMPORTANTE
- Esta versão NÃO apaga as tabelas antigas. Ela usa novas tabelas rds_*.
- A confirmação do pagamento continua manual por segurança.
- Imagem/PDF recebido é tratado como possível comprovante, não como pagamento confirmado.
- O fechamento oficial acontece no botão "Bilhetes enviados ✅".
- Para esta versão não foi criado login por operador; segurança multioperador fica para a etapa final do app.
